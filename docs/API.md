# API

Documentation interactive : `http://localhost:8000/docs`.

Endpoints actifs : `GET /api/v1/health`, `GET /api/v1/courses`, `POST /api/v1/tutor/start` et actions tutor structurées. Les routes `*/status` indiquent explicitement les modules seulement scaffoldés.

Le démarrage du tuteur refuse une génération lorsque aucun document validé ne correspond aux filtres classe/matière.
