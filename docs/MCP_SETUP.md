# MCP et outils

Outils disponibles : terminal PowerShell, recherche/navigation web, ressources MCP génériques, GitHub et contrôle de documents. Aucun serveur Hugging Face ou navigateur pédagogique dédié n'est connecté.

La recherche web intégrée suffit pour l'inventaire. Un MCP Hugging Face n'est pas nécessaire avant la phase de benchmark ; installer un connecteur sans besoin concret augmenterait la surface de secrets et de maintenance.
