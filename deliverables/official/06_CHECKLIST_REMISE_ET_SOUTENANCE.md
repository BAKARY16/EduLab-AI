# Checklist de remise et de soutenance

## Personnalisation des documents

- [ ] Ajouter les noms complets des membres de l’équipe.
- [ ] Ajouter l’établissement, la formation et la promotion.
- [ ] Ajouter le nom du responsable ou du jury si nécessaire.
- [ ] Vérifier la date et la version.
- [ ] Exporter les DOCX en PDF après validation.

## Vérification de la plateforme

- [ ] Frontend actif sur le port 3000.
- [ ] API active sur le port 8000.
- [ ] Service professeur actif sur le port 8010.
- [ ] Connexion avec un compte de démonstration testée.
- [ ] Question Professeur IA testée avant la présentation.
- [ ] Laboratoire et examen de démonstration testés.
- [ ] Aucune clé API ni donnée sensible visible.

## Présentation

- [ ] PowerPoint ouvert localement et polices vérifiées.
- [ ] Vidéo disponible localement, sans dépendre d’Internet.
- [ ] Copie PDF du PowerPoint disponible.
- [ ] Démonstration de secours préparée avec captures d’écran.
- [ ] Réponses préparées sur les données, modèles, limites et coût.

## Remise

- [ ] Code source nettoyé sans `.env.local`.
- [ ] README et guide d’installation inclus.
- [ ] Notebooks Data/ML inclus.
- [ ] Rapports de tests et métriques inclus.
- [ ] Sources et licences des contenus vérifiées.
